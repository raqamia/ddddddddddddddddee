# لوحة تحكم منارة (Admin Panel)

لوحة ويب لإدارة التطبيق بالكامل دون الدخول إلى Supabase: إحصائيات المستخدمين،
إدارة المواد، رفع ملفات/كتب PDF، عرض المستخدمين، وإرسال إشعارات داخل التطبيق.

## التشغيل لأول مرة

1. **طبّق `SETUP.sql`** في Supabase → SQL Editor (ينشئ صلاحية المشرف، جدول الإشعارات،
   سياسات التخزين، وعمود "آخر ظهور").
2. **عيّن نفسك مشرفًا:** في جدول `profiles` نفّذ:
   ```sql
   update public.profiles set is_admin = true where email = 'بريدك@مثال.com';
   ```
   (يجب أن يكون لديك حساب في التطبيق بهذا البريد أولًا.)
3. **أنشئ bucket** باسم `pdfs` (Private) من لوحة Supabase Storage إن لم يُنشأ تلقائيًا.
4. افتح `admin/index.html` في المتصفّح، وسجّل الدخول ببريد المشرف وكلمة المرور.

> الإعدادات (Supabase URL و anon key) مهيّأة مسبقًا لمشروعك، ويمكن تغييرها من شاشة
> الدخول (⚙️ إعدادات الاتصال).

## الأمان
- اللوحة تستخدم مفتاح `anon` العام + تسجيل دخول المشرف، والصلاحيات محميّة بسياسات RLS
  (`is_admin`). آمنة للنشر على الويب (GitHub Pages / Netlify / Vercel).
- **لا تستخدم مفتاح `service_role` هنا** إن كنت ستنشرها على الإنترنت.

## ملاحظات
- **الإشعارات داخل التطبيق:** ✅ منفّذة بالكامل. التطبيق فيه شاشة "الإشعارات"
  (أيقونة الجرس في الرئيسية) تقرأ جدول `notifications` وتعرض ما ترسله من اللوحة.
- **عدد النشطين:** ✅ مفعّل. التطبيق يستدعي `touch_last_seen()` عند فتح الشاشة الرئيسية
  لتحديث `last_seen` تلقائيًا.
- **إشعارات Push (FCM):** تظهر والتطبيق مغلق — مهمة منفصلة أكبر تتطلب إعداد Firebase
  (`google-services.json`) وتعديلات على التطبيق. غير مشمولة بعد.
